# Satisfying 2D Physics Simulation Framework

A reusable, modular framework for creating short-form physics videos using:

- **Matter.js** for physics
- **p5.js** for rendering
- **Tone.js** for procedural audio
- **TypeScript** for scalable structure

This project is designed so each new video concept lives in its own folder and plugs into shared framework components.

---

## Tech Stack

- Browser runtime with CDN scripts (no bundler required)
- TypeScript source compiled to ES modules in `dist/`

## Architecture Overview

### `SimManager`

Central simulation controller:

- owns Matter engine/world
- updates and renders entities
- handles collisions and audio notes
- supports global physics config (`gravity`, `timeScale`, motion scaling)
- evaluates end conditions (e.g., last ball standing)

### `SimEntity`

Base class for all reusable scene objects:

- `update()`
- `show()`

### Reusable entities

- `SimBall`: configurable durability, collision behavior, speed scaling on hit
- `SimBoundary`: static rectangle
- `SimHollowCircle`: static segmented ring
- `SimSpike`: static spike polygon

### End Conditions

Conditions are modular classes under `src/core/conditions/`.
Current implementation includes `LastBallStandingCondition`.

## Video System (Per-Video Folder)

Each video lives in its own folder under `src/videos/` and implements `VideoScene`.

Example:

- `src/videos/video-001-hollow-ring/HollowRingVideo.ts`
- `src/videos/video-001-hollow-ring/index.ts`

Register each video in:

- `src/videos/registry.ts`

This keeps previous videos trackable and reusable while allowing independent scene configs.

---

## Configurability Patterns

Use per-video config objects to tune behavior without touching framework internals.

Current video config supports:

- ball count
- bounciness/restitution
- start direction and speed
- gravity/time scale
- hit-point durability (e.g., 3-hit death)
- collision-source damage filters
- per-collision speed multipliers (wall vs ball vs spike)

Example idea:

- disable wall damage but still speed up on wall hit
- allow damage only from spikes in another video

## How to Add a New Video

1. Create folder:

```text
src/videos/video-00X-my-concept/
```

2. Add scene class extending `VideoScene`:

- `MyConceptVideo.ts`

3. Add `index.ts` exporting a `VideoDefinition`.

4. Register in `src/videos/registry.ts`.

5. Build and run.
